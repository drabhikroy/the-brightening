# Assets

Every icon file here is generated by `Scripts/make_icons.py`. Edit the script,
not the output, then run it from the repository root:

```bash
python3 Scripts/make_icons.py
```

The SVG files hold shapes and colors only, with no title, description,
comments, or editor data. The PNG files hold image data only, with no text,
time, or color profile chunks.

## Files

| File | Purpose |
| --- | --- |
| `AppIcon.svg` | The full icon on its rounded tile |
| `Icon-Transparent.svg` | No tile, for README rows and pages. Adapts to light and dark appearance |
| `Icon-Tile.svg` | A 48 unit dark tile with a corner radius of 7, matching the other projects |
| `Icon-Mono.svg` | One color through `currentColor`, for places that tint the mark |
| `MenuBarIcon.svg` | The 18 point menu bar template, for reference |
| `png/AppIcon-N.png` | The app icon at 16, 24, 32, 48, 64, 128, 256, 512, and 1024 pixels |
| `png/Icon-Tile-N.png` | The tile at 16, 24, 32, and 48 pixels |

`build.sh` turns the `AppIcon` PNG files into the `AppIcon.icns` file inside
the app bundle, so the icon in the Dock, in Finder, and in the README is
always the one design.

## What the icon shows

A display sits in the lower half of the tile. A sun is centered on its top
edge, so the lower half of the sun is inside the screen and the upper half
rises out past the bezel with its rays. The part inside the screen is a
muted gold and the part above is bright, which is the app in one picture.
The screen has a ceiling, and the app lets the picture go above it.

## Menu bar

The menu bar icon is the same picture as a one color template on the 18
point grid a status item uses. It keeps five of the eight rays, because eight
merge together at that size, and it shows the half of the sun inside the
screen at 45 percent opacity instead of in muted gold.

The app draws this icon in `Sources/MenuBarIcon.swift` rather than loading a
file, so it stays sharp at any scale and macOS can recolor it for a light or
dark menu bar. `MenuBarIcon.svg` is written from the same numbers so the
shape can be seen and checked outside the app. If you change one, change the
other to match.

## Color

| Role | Value |
| --- | --- |
| Tile | `#11161C` |
| Bezel | `#5A6675` |
| Screen | `#1B232C` |
| Sun above the screen and rays | `#FFD25E` |
| Sun inside the screen | `#C8902F` |
| Sun and rays on a light page | `#C47A0A` |
| Bezel on a dark page | `#7A8592` |

The two page colors only apply to `Icon-Transparent.svg`. On a white page the
bright sun falls to about 1.4 to 1 contrast, so light appearance switches to
a deeper amber that holds 3 to 1. On a dark page the tile gray bezel would
fade out, so dark appearance lightens it.

Every shape is a flat fill. There are no gradients, shadows, or highlights,
which keeps the files small and leaves macOS free to add its own treatment.

## Small sizes

The display and the sun hold up down to 24 pixels. At 16 pixels the rays
merge into a bright band above the screen, which still reads as light coming
off the top. That is fine for a Finder list, but the README rows should use
the 40 to 48 pixel range.
