The Brightening raises the brightness of a MacBook Pro's Liquid Retina XDR
display above the usual limit for everyday content. It lives in the menu bar.
Click the icon, turn the boost on, and set the level.

## What it does

- Lets ordinary windows use some of the extended range the display keeps for
  HDR highlights
- Sets the boost from 100 to 160 percent with one slider, and remembers it
- Puts the boost back on its own after sleep or a display change
- Starts at login if you want it to
- Puts the display back exactly as it was when you turn it off or quit
- Runs entirely on your Mac, with no account, no server, and no network
  connections

## Install

Download `The-Brightening-1.0.0.pkg` below and open it. macOS asks for an
administrator password because the app goes into the Applications folder.
The app opens in the menu bar when the installer finishes.

## Requirements

A MacBook Pro with a Liquid Retina XDR display, which means a 14 inch or
16 inch model with Apple silicon from 2021 or later, running macOS 27 or
later.

## Verify the download

`SHA256SUMS.txt` is published with this release. With it in the same folder
as the package, run this command.

```bash
shasum -a 256 -c SHA256SUMS.txt
```
