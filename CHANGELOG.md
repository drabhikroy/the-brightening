# Changelog

Notable changes to The Brightening. Versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). Dates are ISO 8601.

## [1.0.0] - 2026-10-14

The first public release.

### Added

- A menu bar app that raises the brightness of a MacBook Pro's built-in
  Liquid Retina XDR display above the usual limit for everyday content.
- A popover with a power button and a level slider from 100 to 160 percent,
  with the setting remembered between launches.
- Automatic recovery after sleep, display changes, and resets by other apps.
- Launch at Login for a copy installed in the Applications folder.
- An About window, opened from the popover or by right-clicking the menu bar
  icon, with the version, the license, and a link to the latest release.
- VoiceOver labels, keyboard control, a visible focus ring, Reduce Motion
  support, and WCAG 2.2 AA contrast in light and dark appearance.
- A signed and notarized installer that quits a running copy before
  replacing it and opens the new copy afterward.
